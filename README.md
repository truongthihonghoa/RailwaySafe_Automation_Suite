# 🚆 RailwaySafe Automation Test Project

## 📌 Overview
This project contains automated test scripts for the RailwaySafe system.  
It focuses on verifying core functionalities such as authentication, booking tickets, and password management.

---

## ⚙️ Technologies Used
- Selenium WebDriver
- TestNG (Java testing framework)
- Java
- Maven / Gradle
- Git & GitHub

---

## 🧪 Test Coverage
- User Authentication (Login / Logout)
- Ticket Booking Flow
- Change Password Feature
- Basic End-to-End User Flows

---

## 🚀 How to Run the Tests

```bash
# Install dependencies (Maven example)
mvn clean install

# Run TestNG suite
mvn test
